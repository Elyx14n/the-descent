# Glossary format

Use root `GLOSSARY.md` for this game's domain terms.

```markdown
# The Descent — Glossary

## Monastery spaces

**Arrangement**: An authored configuration of room and passage placements and their connections.
```

Keep definitions to one or two sentences. Use existing glossary terms within definitions. Add `_Avoid_: ...` only for a real naming ambiguity; scope restrictions and rejected gameplay ideas belong in `PRODUCT.md`.

Group terms when useful. Implementation details and general programming vocabulary belong elsewhere.
